# Suneel Marabathena — Portfolio

Professional portfolio built with HTML, CSS and JavaScript.

## Included
- Responsive modern design
- Home, About, Skills, Projects, Education, Certifications and Contact
- Mobile navigation
- Project cards
- Smooth scrolling
- Lightweight reveal animations
- Direct email and phone links

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize
Update the LinkedIn and GitHub URLs in `index.html` with your real profile URLs.
